The site behind the launch post is synacl.com, a small IoT company's site with product pages, guides and a few browser tools. This Monday we ran the released siteread on it for the first time, next to the script it came from. One number stood out, and most of this post is about how far it can be trusted.

The number

People whose first visit came from ChatGPT: 3 in the week of 10-10 to 10-16, 23 in the week of 10-17 to 10-23. Over 28 days, 45. They landed on the tools more than the articles: the ESP32 web flasher (13), the Modbus RTU tool (13), the ESP32 info tool (6) and the serial monitor (5).

Twenty-three people is a small number. It is one week, and one week can be one Reddit thread or one answer ChatGPT happened to give a lot that week. What we can say is that it is not the whole site rising: Google and Reddit grew by about two thirds and direct by a seventh, while ChatGPT grew sevenfold.

Search Console saw none of it

Search Console reported 114 clicks over the same 28 days. The log counted 117 people arriving from Google. That match is the reason we trust the log's other rows: the rule that decides who is a person (a browser that loaded a stylesheet, never probed for /.env, not a cloud address faking a Google Referer) sees the same readers Google does.

ChatGPT's visitors are not in Search Console at all. Most of them send no Referer either. They show up because ChatGPT tags its links ?utm_source=chatgpt.com, and siteread reads that tag before the Referer. Without it, those 23 people would have been filed under "direct".

The crawler side moved too

Verified fetches of sitemap URLs per week, four weeks to 10-23, counting only IPs inside each vendor's published list:

OAI-SearchBot more than doubled its fetches in the same week ChatGPT's visitors went from 3 to 23, and bingbot rose too. That is a timing fact, not a cause: we cannot see inside either index. But it is the first week where the crawl and the visits moved together, and it is the kind of thing a weekly read exists to notice.

The fakes are still there. In the same 28 days, requests wearing a Googlebot user-agent from outside Google's list: 28. ChatGPT-User: 25. ClaudeBot: 12. Counting user-agents would have added them all to the totals above.

What the first real run found wrong in siteread

Running the tool and our old script on the same log gave the same answers to within a few people: Google 117 against 122, ChatGPT 45 against 46, every goal equal. The old script had one bug siteread did not: it took the flasher's own JavaScript, served from a /assets/vendor/ path, for a scanner probe and dropped every person who used the flasher.

siteread had bugs of its own, fixed in 0.3.0 the same morning:

  • Search Console lists a jump link (/guide/#step-2) as its own page row. siteread summed it into the page, and one guide read 568 impressions where Search Console said 539. Fragment rows now stay as Search Console gives them.
  • DuckAssistBot, DuckDuckBot, MistralAI-User and CCBot publish IP lists; siteread now checks against them instead of calling them unverified.
  • A click from duck.ai, DuckDuckGo's chat, was counted as a referral. It is an assistant's answer, and now counts as AI, as do Mistral's, Grok's and Meta AI's chats.
  • The weekly "people" number includes returning readers; the per-source numbers are first arrivals. Both are now in the digest, labelled, so a memo never sets one against the other.
  • The site's team uses an admin app on another host, which --team-path cannot see. --team-host marks anyone who used that host as team. Excluding the team by IP had been the fallback, and it was dropping strangers: some of those addresses looked like a mobile carrier's shared ones and iCloud Private Relay's, which many people use at once.

What we will watch

Whether 23 holds next week. If ChatGPT keeps sending people to the tools, the tools are what to build more of; if it falls back to 3, this post is the record that it happened once. Either way the number goes in the log, dated, next to the crawl that came with it.

siteread 0.3.0 is on npm. The docs have every command; the weekly memo comes from the seo-read skill in its Claude Code plugin.
