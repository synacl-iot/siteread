How a weekly read works

1 · digest

Turn the files into numbers

People by first touch, Search Console weeks with impression-weighted position, every crawler verified against its vendor's list.

npx siteread digest --gsc export.zip \
  --log access.log --out .siteread/digests
2 · memo

Read it as a dated memo

The seo-read skill for Claude Code writes the week up: what changed, who came from where, which crawler read what, and two to four things to do next.

{{ install }}
3 · share, if you want

See where you stand

Send one week's numbers to the benchmark and see where each stands among the published quartiles. It prints every byte first and sends nothing without a yes.

npx siteread share --dry-run
